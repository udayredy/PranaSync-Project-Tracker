## How ownership and progress are shown

Current role and file assignment comes from `docs/TEAM_ROLES.md` and `docs/PROJECT_SUMMARY_WEEK9.md`. Remaining work comes from `docs/TEAM_TASKS.md`. Historical branch mapping comes from `docs/TEAM_WORK_SPLIT.md` and `docs/TEAM_GITHUB_PLAN.md`. Where these sources conflict, the task note says so. Role assignment is not proof of individual authorship.

- **Done** means the archive contains the deliverable or an archived report records its completion.
- **In progress** means the implementation exists but the final task list says follow-up remains, or the historical branch status is not confirmed complete on main.
- **Next sprint** means `TEAM_TASKS.md` identifies the work as outstanding.
